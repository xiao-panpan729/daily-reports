## 一、表结构（长表，不是嵌套 JSON）

**为什么必须改长表**：现有 `macro_monthly.json` 是 `{指标: {month, value}}` 的嵌套结构。
每个指标各带各月份 → 拼在一起时"最新月份"横跨好几个时点（2026-04 社融 + 2026-08 M2 + 2026-07 房价），
看着像一张截面表，实际是碎片。**改用长表后，时间错配在结构上不可能发生**——
"这是什么时候的数据"变成行内字段，不再是隐含假设。

一行 = 一个观测值。字段：

| 字段 | 说明 | 例 |
|---|---|---|
| `metric_id` | 指标唯一 ID，点号分层 | `pboc.loan.household.ml.consume` |
| `name` | 中文名 | 住户中长期消费贷款 |
| `layer` | L1 事实 / L2 指引 / L3 智库 / L4 市场 | `L1` |
| `category` | 货币/信贷/财政/税收/支出/实体/价格/对外 | `信贷` |
| `parent_id` | 父指标，构成分项树 | `pboc.loan.household.ml` |
| `value` | 数值 | `480576.92` |
| `unit` | 单位 | `亿元` |
| `yoy` | 同比 %（源直接给才填，不自算） | `-14.5` |
| `freq` | M 月 / Q 季 / D 日 / EVENT 事件 | `M` |
| `period` | **数据属期**（哪个月的数据） | `2026-08` |
| `stat_type` | balance 余额 / cumulative 累计 / flow 增量 | `balance` |
| `published_at` | **实际挂网日** | `2026-09-14` |
| `source` / `source_url` | 来源与可回溯链接 | — |

⚠️ `period` 与 `published_at` 必须同时存在。只写一个就会出现"这个 8 月的数据我什么时候知道的"这类无法回答的问题。
⚠️ `stat_type` 必须标。**余额差分才是增量，累计值差分才是单月值**——混用是最容易犯的错。

## 三、本次新建的三条抓取（已跑通）

### 3.1 央行《金融机构人民币信贷收支表》 ✅ 136 条
- 入口 `pbc.gov.cn/diaochatongjisi/116219/116319/2026ntjsj/jrjgxdsztj/index.html`
- 抓 index → 正则定位表名 → 取其后最近 `.xlsx` → `pd.read_excel` 解析
- 实测：56 行科目 × 12 个月，**17 个指标 × 8 个月 = 136 条**
- 分项树（平衡关系自校验：住户短期 + 住户中长期 = 住户贷款 ✓）

```
pboc.loan.total            各项贷款
├─ pboc.loan.domestic      境内贷款
│  ├─ pboc.loan.household  1.住户贷款
│  │  ├─ .short  （1）短期贷款
│  │  │  ├─ .consume   消费贷款   ← 8月 86113.85 亿
│  │  │  └─ .operate   经营贷款   ← 8月 107384.02 亿
│  │  └─ .ml     （2）中长期贷款
│  │     ├─ .consume   消费贷款   ← 8月 480576.92 亿
│  │     └─ .operate   经营贷款   ← 8月 148360.79 亿
│  ├─ pboc.loan.corp       2.企（事）业单位贷款
│  │  ├─ .short/.ml/.bill 票据融资/.lease 融资租赁/.advance 各项垫款
│  │  └─ .nbfi             3.非银行业金融机构贷款
│  └─ pboc.loan.overseas （二）境外贷款
```

**住户贷款 2026-08 增量（差分）= −2007.69 亿**
```
住户贷款合计      −2007.69
  ├ 短期          −1185.44   （消费 −445.26 / 经营 −740.18）
  └ 中长期         −822.24   （消费 −1210.53 / 经营 +388.29）
```
⚠️ **与你提到的 −2029 亿差 21 亿**，口径需对齐——
本表是「金融机构」口径（含央行 + 存款类 + 非存款类银行机构）。
若你看到的是「**存款类**金融机构人民币信贷收支表」口径，是另一张表（index 页第 6 个链接），需另抓比对。
**这个差异必须先对齐再下结论，不要两个数混着用。**

⚠️ **本表是余额，不是增量。** 算"新增"必须差分；1、2 月分开列可直接差分，但跨年时要小心。

## 四、下一步：统计局 EasyQuery 是"整张网"的骨架

`data.stats.gov.cn/easyquery.htm` 是**未公开文档的 JSON API**，一个入口覆盖统计局全部指标
（国家/省/市三级 × 月/季/年）：

```
POST/GET https://data.stats.gov.cn/easyquery.htm
  m=QueryData
  dbcode=hgyd        # hgyd 月度国家 / hgjd 季度国家 / hgnd 年度国家
                     # fsyd 月度省级 / hgjd…
  rowcode=sj         # 行 = 时间
  colcode=zb         # 列 = 指标
  wds=[]             # 固定筛选
  dfwds=[{"wdcode":"zb","valuecode":"A020101"}]   # 指标筛选
  k1=<毫秒时间戳>     # 必带
  h=1
```

配套还有两个接口：
- **`search.htm?s=<关键词>`** → 直接返回指标 code，**一次请求定位 zb，不用 getTree 逐层下钻**
- `easyquery.htm?m=getTree&id=zb` → 浏览指标树

**为什么这条比 akshare 更值**：akshare 是一指标一函数、各接口存活状态参差（本次实测 10 个已死）；
EasyQuery 是**统一入口 + 统一返回结构**，社零/工业增加值/固投/房价/失业率全走同一条路，
一次写好解析器，加指标只改 code。这才是"整张网"该有的骨架。

⚠️ 注意：`data.stats.gov.cn` 对**境外网络**会超时/403（本机在国内，直连应无碍，但需实测）。
