# 04 · 世界观面板视觉设计（想法与方案）

> 2026-09-03。用户对"世界观面板"的核心视觉构想 + 实现方案拆解。
> 目标：把 220+ 个世界读数，压成一张"一眼看懂世界当前在交易什么"的态势图。

---

## 一、用户原意（要的那个感觉）

> "就像资金流入流出的那个大圆圈小圆圈图一样，圆圈大小是权重，在一个平面上或一个象限（四象限），每个象限上有大有小，感受世界的每一个方向。当前市场一直在交易的是什么。球体大小代表权重，颜色设计一个涨水的形式，代表热度递增还是递减。"

**三个视觉编码，缺一不可：**

| 编码 | 含义 | 用户原话 |
|---|---|---|
| **球体大小** | 权重 = 该方向在当前世界的重要性 / 被交易的活跃度 | "圆圈大小是权重" |
| **球体颜色** | 热度方向 = 升温 or 降温（"涨水"的涨落感） | "颜色…代表热度递增还是递减" |
| **布局（象限）** | 把世界各方向摊开，分门别类 | "四象限…感受世界的每一个方向" |

**核心追问（这是面板的灵魂）："当前市场一直在交易的是什么？"**
→ 大小回答"在哪"，颜色回答"在加速还是退潮"。

## 二、数学：一阶导 / 二阶导 → 图形表达

用户明确要"一阶导、二阶导的递增数据"，并问"怎么用图形形象表达在一个球里"。

- **水平（值本身）** → 球体大小。当前价格/概率/收益率的绝对高低。
- **一阶导（变化速度）** → 颜色深浅。`Δ = 今日值 − 昨日值`，正=升温(涨色)、负=降温(跌色)。
- **二阶导（加速度）** → 颜色的"冲劲"。`ΔΔ = 今日Δ − 昨日Δ`，正=加速升温、负=开始退潮。

**关键洞察：二阶导比一阶导更有信息量**——它回答的不是"涨了没"，而是"这股劲是在变强还是衰竭"（转折点就藏在这里，正好对上用户之前说的"世界有周期、有转折、有持续度"）。

### 图形化方案（球体怎么"涨水"）

- **球体内部用"水位"表达**：球内填充从底部往上的一条水位线，水位高度 = 标准化后的动量强度。
- **颜色用热力渐变**：
  - 升温（Δ>0）：红→橙→黄（越热越亮）
  - 降温（Δ<0）：绿→蓝→深蓝（越冷越暗）
  - 中性（Δ≈0）：灰
- **二阶导用"外圈光环/脉冲"**：加速（ΔΔ>0）给球体加一层向外扩散的光晕（呼吸感），减速（ΔΔ<0）光晕收缩或消失。这样"涨水"的动势一眼可见。

> 注：A股惯例 涨=红/跌=绿（已在系统约定里），这里沿用——升温红、降温绿。

## 三、布局：象限划分

第一版建议**四象限**，横轴 + 纵轴各一个二分：

- **横轴**：风险偏好 —— 左"避险"(risk-off) / 右"风险"(risk-on)
- **纵轴**：区域/资产类别 —— 上"美国/全球" / 下"中国/亚洲"

每个球按它的属性落位，大小=权重，颜色=热度，天然形成"世界引力场"。

| 象限 | 落位方向 |
|---|---|
| 右上 全球·风险 | AI算力、加密、美股科技 |
| 左上 全球·避险 | 黄金、美债、美元、VIX |
| 右下 亚洲·风险 | 恒生科技、港股、新兴 |
| 左下 亚洲·避险 | 中债、人民币、国内流动性 |

## 四、第一版范围（简单但完整）

1. **一张静态 HTML 态势屏**（本地文件，浏览器打开），先吃 `snapshots.csv` 最新一次快照。
2. 布局：四象限 + 球体（大小/颜色/光环三编码）。
3. 数据：先聚焦**焦点层 20 个 HIP-3 + 外部 13 个宏观**，不铺 220 个全量（避免拥挤）。
4. 每个球 hover 显示：名称、值、Δ、ΔΔ、持续天数(streak)。
5. 顶部一行摘要：今日快照时间 + "当前市场在交易什么"的一句话（先用规则生成，后接 LLM）。

**不做的（留到 v2）**：动画实时刷新、220 全量、LLM 判读、历史回放。

## 五、已确认决策（2026-09-03 定）

| 决策点 | 结论 |
|---|---|
| 颜色方向 | **升温=红 / 降温=绿**（A股惯例）✅ |
| 象限轴 | **风险偏好（避险←→风险）× 区域（美国/全球←→中国/亚洲）** ✅ |
| 权重定义 | **方案 A：球大小 = 今日动量 \|delta\|**（对数缩放）。画的是"此刻世界在哪块用力"，不是静态重要性排行榜 ✅ |
| 标的范围 | 第一版 33 核心（20 FOCUS + 13 外部宏观），布局不紧张可加到 50-100 |
| 二阶导外圈 | 先保留（\|d2\|>0.003 画虚线外圈，加速红/减速绿），阈值待调，不强求 ✅ |
| 数据质量问题 | FRED/DXY/VIX/HSI 等日更源在非更新日 delta=0，标灰「无新数据」，不假装平静 |

### 权重定义的两条路线（已选 A）

- **方案 A（已选）**：球大小 = 动量（\|delta\|）。优点：用现有数据 100% 能做对，且对齐"感受当下"的目标。缺点：不区分"垃圾币暴涨"和"重要资产异动"。
- **方案 B（未选）**：球大小 = 固定先验重要性权重。稳定但看不出"当下"。
