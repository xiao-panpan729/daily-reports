### 🟡 偏高 货币空转（中国）
- 逻辑：M2增速 > GDP增速 → 钱没进实体 → 在金融体系空转 → 风险积累
- 当前：M2 7.5% − GDP 5.2% = 2.3pp
- 含义：缺口越大，宽松越进不了实体，越利好金融资产/债市、越挤压银行息差

### 🔴 危险 通胀消化缺口（中美）
- 逻辑：M2增速 − CPI增速 = 货币消化能力；缺口大 = 发的钱没被通胀吸收 → 堆在资产价格里
- 当前：中国 7.5−0.8 = 6.7pp；美国 5.66−3.71 = 2.0pp
- 含义：中国缺口大=极弱通胀、宽松无效化；美国缺口小=货币正常化接近完成

### 🔴 危险 货币政策分化（中美利差）
- 逻辑：中美10Y利差倒挂 → 资本外流压力 → 人民币承压 → 央行降息空间受限
- 当前：CN10Y 1.68% − US10Y 5.11% = -3.43pp
- 含义：倒挂越深，降息越受汇率约束，宽松需要'精准滴灌'而非大水漫灌

### 🔴 同步收缩 经济动能对比（PMI + 初请）
- 逻辑：中美 PMI 同步性 → 全球周期方向；美国初请失业金（周频）是动能的高频验证器
