> 2026-09-03。调研目标：为世界观面板的"权重"补上「热度/参与人数/讨论度」这类资金流量级数据，**优先复用现成项目，不重复造轮子**。

## 二、三个数据源详情

### 1. ApeWisdom（Reddit/4chan 讨论度）—— 核心推荐

- **地址**：`https://apewisdom.io/api/v1.0/filter/all-stocks/page/1`
- **本质**：专门统计 r/wallstreetbets、r/stocks、r/CryptoCurrency 等 subreddit + 4chan /biz 里每个 ticker 被提及的次数。每半小时扫一次，识别大写或 `$` 前缀的 ticker，同一帖/评论重复提及只算一次。
- **免 key，直接 HTTPS GET**，返回 JSON。
- **字段**（每个结果）：
  - `ticker`、`mentions`（近24h 提及次数）、`mentions_24h_ago`（前24h）
  - `rank`（今日排名）、`rank_24h_ago`（昨日排名）
  - `upvotes`、`sentiment` 等
- **实测样例**（2026-09-03）：AVGO mentions 91→676，rank 7→1（热度暴增的真实信号）
- **filter 可选**：`all-stocks` / `all-crypto` / `wallstreetbets` / `SPACs` 等
- **注意**：它是"散户注意力/情绪"信号，不是基本面，噪声大（可能被刷、讽刺、水军）。适合做**辅助权重**，不能单独当买卖依据。

### 2. akshare 东财人气榜（A股热度）

- **接口**：`ak.stock_hot_rank_em()` → 返回「当前排名/代码/名称/最新价/涨跌额/涨跌幅」
- **本质**：东方财富的个股人气榜，反映 A股散户关注度
- 相关接口还有：`stock_hot_rank_detail_em`（历史趋势）、`stock_hot_rank_detail_realtime_em`（实时变动）、`stock_hot_keyword_em`（关键词）
- **注意**：这只覆盖 A股，正好补 ApeWisdom（只覆盖美股/加密）的缺口。

### 3. Alternative.me 恐惧贪婪指数（加密情绪）

- **接口**：`https://api.alternative.me/fng/?limit=N` → 返回 0-100 的值 + `value_classification`（Extreme Fear/Fear/Neutral/Greed/Extreme Greed）+ 历史序列
- **本质**：综合波动率、动量、社交、市场占比等算的加密全市场情绪
- 实测当前 65 = Greed

## 三、为什么放弃"自己训情绪模型"的路线

调研到的 Reddit sentiment 项目（Kapil1917T、NavnoorBawa、vedik2002、tamdogood/redsen 等）大多是**学生/portfolio 项目**，问题一致：
1. 需要自己注册 Reddit API key（PRAW），或训 FinBERT（重、维护成本高）；
2. 用 Tweepy 的项目 Twitter API 已失效；
3. 有的是几年前的，依赖可能已挂。

**而 ApeWisdom 已经把"统计提及次数"这件事做完了，还免费免 key**——这就是"不重复造轮子"的最佳答案。我们要的是**讨论度的数字**（mentions/rank/变化），不是情绪分类标签，ApeWisdom 直接给。

## 四、接入方案（v2 待做，等数据源稳定）

世界观面板的权重升级为**三因子混合**：

```
球体权重 = 动量因子(|delta|) + 讨论度因子(mentions/rank变化) + 情绪因子(恐惧贪婪)
```

### 采集层新增模块（建议加进 world_feed.py）

| 新数据源 | 采集内容 | 落库 key 前缀 | 频率 |
|---|---|---|---|
| ApeWisdom | 美股/加密 ticker mentions + rank + 24h变化 | `social:` | 日更 |
| akshare 人气榜 | A股人气排名 | `hot:` | 日更 |
| Alternative.me | 加密恐惧贪婪指数 | `fng:` | 日更 |
| (备选) tushare | A股资金流（北向/主力/两融） | `flow:` | 日更 |

### 数据落库位置
- 快照 → `data/snapshots.csv`（新 source 列：`social` / `hot` / `fng`）
- 历史 → `data/history.csv`（累积，供二阶导计算）

### 权重公式（v2 草案，待实测调参）
```
weight = w1 * log(1+|delta|) + w2 * log(1+mentions) + w3 * |rank变化|
```
`rank变化`（今日rank − 昨日rank）本身就是讨论度的"二阶导"，正好和现有的一阶/二阶导体系对齐。
