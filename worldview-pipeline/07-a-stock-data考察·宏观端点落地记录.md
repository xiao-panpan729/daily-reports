# 07 · a-stock-data 考察 · 宏观端点落地记录

> 2026-09-08。背景：akshare 金十源 2025-09 后停更（CN CPI/GDP、US ISM 冻结），恰好 simonlin1212/a-stock-data（V3.7.0+，Apache-2.0）新增了官方直连的宏观层。本文记录考察结论与已落地部分。

## 一、项目概况

- 定位：单文件 SKILL.md 的 A 股全栈数据工具包，12 层 · 60 端点 · 19 数据源，除 iwencai 外全部零鉴权。
- V3.0 起去 akshare 依赖、直连 HTTP/TCP（mootdx/腾讯/东财/同花顺/百度/巨潮/财联社…）。
- V3.7 新增宏观层：人民银行社融 + 国家统计局 PMI（2026-08-19 全端点实跑验证）。

## 二、宏观层对我们（世界观第5模块）的适配结论

| 缺口 | 项目有解吗 | 处置 |
|---|---|---|
| 中国 CPI（金十停更） | 无现成端点，但有统计局抓取套路 | ✅ 照 PMI 套路自写 `nbs_cpi()`，实测 2026-07 CPI +0.5% |
| 中国 PMI（金十停更） | ✅ §11.2 统计局 PMI | ✅ 已移植 `nbs_pmi()`，2026-08 制造业 49.8 |
| 中国社融（原本没有） | ✅ §11.1 人行社融（12 列 xls 三级跳） | ✅ 已移植 `pboc_social_financing()`，新增链6 |
| 美国 ISM（金十停更） | ✗（美股数据在姊妹项目 global-stock-data，且 FRED 无 ISM） | 用 FRED ICSA 初请失业金（周频）替补动能读数 |
| US CPI / M2 | 本来就走 FRED | 不变 |

已移植代码位于 `macro_insight.py`（标注改自 a-stock-data，Apache-2.0）。
首读信号：**滚动12月社融增量同比 -9.4% → 链6 判 🔴 收缩**。

## 三、项目里其他值得收藏的（暂不接）

- **财联社快讯（分钟级直连）**：worldview 新闻侧的候选源，比 ApeWisdom 更"中国语境"。
- **北向资金 / 龙虎榜 / 两融 / 大宗 / 解禁**：属 quantify-per 执行域（03 文档已定边界），不进世界观。
- **ETF 期权 T 型报价 / 希腊字母**：新玩具，等期权监控需求出现再看。
- **方法论本身**："去 akshare 直连 HTTP + fail-fast + 主源被封备用源降级"值得借鉴——我们保留 akshare 的中债/货币网两条（实测稳定），其余关键链路已有直连兜底。

## 四、注意

- 社融端点仅支持 2021+（旧版式解析不可靠，fail-fast 抛错）。
- 统计局正文措辞变更会使解析失败——代码里已是 fail-fast，日报里会显示缺数据而不是假数。
- US ISM 仅作历史对照标注，链4 主力读数换成 ICSA 周频。
