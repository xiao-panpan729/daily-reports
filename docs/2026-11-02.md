## 🔴 消息面要点

**① [🔴核心] 政策端出手托底资本市场工具 → 情绪修复先行，增量资金待验证**

11月2日央行、证监会、金管局召集各大银行和基金公司开会，主题是「推动支持资本市场工具使用」，点名优化股票回购增持再贷款。猫笔刀把账算得很清楚：再贷款3000亿＋互换便利5000亿，授权8000亿，实际落地只有2000多亿，因为银行只赚0.5%息差却要背股票坏账，有实力的企业不差钱，缺钱的企业过不了审。他判断这次不是提额度，是研究怎么把额度花出去，象征意义大于实际影响。表舅补了一层：互换便利上量快、但近几个季度货政报告已经不提了，因为25年以来股市里的钱已经太多；再贷款一直小步慢跑，卡点在税费政策，这才是「优化」的题中之义。会还没开完就传出国有大行向国新、诚通各新增1000亿专项贷款额度，猫笔刀理解为国家队席位加杠杆，主流宽基建仓为主。落到交易上，这是情绪面的正面变量，不是资金面的。⏰ 11月2日开会，专项贷款额度待落地

**② [🔴核心] 全球AI硬件同步杀估值 → 贵是原罪，从市梦率切换到摁计算器**

上周五费城半导体指数跌7%，英特尔单日-28.6%，纳指-3%，黄金重挫近4%创一年新低。表舅把全球AI核心公司从高点回撤排了一遍：中位数-44%，创业板指-45%正好在中位，科创50-49%在上半区，所谓「海外输入性风险」有了具体数字。他自己的结论很硬：AI产业革命还会继续，但投资上要放弃幻想，进入摁计算器的大分化时代，很多A股科技杂毛票回不到这轮高点——因为科创50腰斩完市盈率还接近100倍。亨特给了另一面：中信统计电子＋通信整体法PE从74倍压到42.4倍，降幅42.8%，三个月走完2022年新能源六个月的杀跌，跌速已经过分，短期反弹概率在提升。但他明确不参与，理由是这轮套牢盘远多于2022年，抛压更重，且看不到类似coding的新叙事。⏰ 10月31日美股收盘；A股三季报披露完毕

**③ [🟡结构性] 全球利率higher for longer → 流动性抽水，避险资产换锚**

材料显示美联储12月加息概率72%，澳洲联储周二预计第五次加息至4.85%创18年高，日本央行把ETF年减持规模从3300亿日元提到8600亿。表舅的框架是股价＝估值×盈利×流动性，估值这条现在由海外高利率主导，而美联储决策本质上取决于中东局势，无法预测，所以只能做好higher for longer的准备。他点出一个真正的积极信号：10月以来费半与长端美债TLT日收益率相关系数-0.56%，是年内极值，股债负相关回归意味着美债重新具备避险属性；反过来费半和黄金同向暴跌，说明黄金这次不是避险是流动性。结论是科技与美债再平衡有意义，但人民币资金买美债的核心风险是汇率，此处强调对冲属性而非配置价值。⏰ 12月FOMC；澳洲联储11月3日

**④ [🟡结构性] 中东与霍尔木兹升温 → 原油风险溢价，通胀端再添一把火**

**⑤ [🟡结构性] 拥挤度集体爆破 → 从白银到双创，同一个剧本在加速**

**⑥ [⚪次要] 岁末年初民生政策落地 → 内需是唯一没筹码的方向**

亨特抓了一句被市场忽略的话：五中全会在部署岁末年初工作时提到「加强普惠性、基础性、兜底性民生建设」。这不是新提法，9月底求是网曾连登两周同题文章，现在落到「岁末年初」这个时间位置上，意味着年底要有政策落地。他推测方向是育儿、养老金、低收入人群兜底、灵活就业人员补贴，并强调这是主要机构包括天量量化几乎没有配置、没有筹码的方向。旁证是万圣节各地罕见的宽松态度。这条线现在不涨，但它和科技是跷跷板两端。⏰ 年底政策窗口

### 🧭 在讲什么故事 / 今早是否同源

**① 在交易什么**

昨夜定价的不是「AI不行了」，是「AI的资本开支曲线要打折」。算力芯片-10.01%、晶圆代工-8.62%，领跌的都是英特尔-28.6%、AMD-10.9%、高通-11.1%；英特尔三季报其实不差，杀的是四季度指引150-160亿低于预期170亿，原因是硬件涨价后PC卖不动。这条链很清楚：材料涨价→终端提价→需求反噬→指引下修。存储链-7.7%、半导体设备-6.55%、高速互联-8.65%同跌，但标签是「反抽」，说明周内曾有资金抢反弹、失败后反手砸。

**② 这也是新事，还是旧事**

延续。上周就在杀AI硬件估值，昨夜只是换了个更具体的催化——从「太贵了」换成「英特尔指引」。延续的部分一句话带过：全球AI核心资产从高点回撤中位数-44%，杀估值没停。真正新的是黄金重挫近4%创一年新低，避险资产自己在被杀，这说明昨夜是流动性事件不是风险偏好事件。

**③ 今早有没有同源催化**

同源，而且不止一条。表舅说AI企业收入本质来自大厂资本开支，大厂自由现金流转负＋美元高利率压制债务融资，水位上升变慢，业绩无法线性外推——这直接对应英特尔的指引下修。亨特说这轮套牢盘远超2022年、没有coding级别的新叙事，对应昨夜「反抽失败」。猫菲特给的产业数据是反向的：PCB、覆铜板、800G/1.6T光模块、HBM4E需求仍在，说明杀的是估值不是订单。不同源的是政策端——11月2日金融管理部门开会研究资本市场工具，这条是内因对冲，跟美股催化不在一条线上。

**④ 预计哪些方向会动 + 失效条件**

能跟的只有政策与内需这两条：沪深300、中证500对应政策护盘与国家队宽基建仓，凭什么——2000亿专项贷款额度已落地、会议当日召开；内需民生对应岁末年初政策窗口，凭什么——筹码真空＋时间确定。

科技方向一律不给跟。晶圆代工映射胜率56%对基准51%，只高5个点，不可信；光通信56%等于基准56%，无优势；算力芯片56%对50%，同样不可信。存储链70%、高速互联70%、半导体设备65%胜率虽高，但读数标签是「反抽」——反抽是跌深后的技术性回抽，不是趋势，不得当作可跟方向。若一定要参与，只能按「反抽不追高、只做日内」处理。

【失效条件】逻辑失效：会议仅表态、无额度与细则落地，政策线当日高开低走；数据失效：昨夜高胜率方向（存储/半导体设备/高速互联）今日高开翻绿，说明映射关系已被量化打穿；时间失效：两周内不出现类似coding的新应用叙事，则反弹只是解套盘换手，两周后二次杀业绩；结构失效：公募重仓股与双创权重继续被赎回，任何反弹都会被申赎结构抹平。
